# OpenAI Help Center, Setting up and managing prepaid API billing

[Read the source](https://help.openai.com/en/articles/8264644-setting-up-and-managing-prepaid-api-billing)

## What it found
API use is paid from prepaid credit. The minimum purchase is $5 and the default offered is $10; auto recharge is optional with a $5 minimum; purchased credits expire after one year.

## So AnswerRank
Pilots can be measured before any monthly cost: with only an OpenAI key a full audit is about 45 cents, so three pilots measured three times each fit inside the $5 minimum. PILOTS.md says to change the $10 default to $5 and leave auto recharge off.
