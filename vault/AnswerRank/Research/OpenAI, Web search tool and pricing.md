# OpenAI, Web search tool and pricing

[Read the source](https://developers.openai.com/api/docs/guides/tools-web-search)

## What it found
The Responses API's web_search tool searches the live web, accepts an approximate user_location (city, region, country) and returns url_citation annotations. $10 per 1,000 calls for reasoning models (search content billed as tokens); $25 per 1,000 for others.

## So AnswerRank
The ChatGPT check uses web search from the business's own city, so it sees what a local customer sees, with the sources it used.
